## 🚀 Projects

### 🟢 Zhila — Dispatch System

`Go` `React` `TypeScript` `Docker`

A dispatch system designed to help coordinate field teams and manage incoming requests.

**My role: Backend Developer**

- Developed backend functionality using Go.
- Implemented request detection and grouping by access nodes (PGP).
- Developed a risk-alerting mechanism.
- Worked on API and integration tests.
- Created a custom benchmarking tool.

---

### 🎓 EduFlow — EdTech Platform

`Node.js` `TypeScript` `Express` `SQLite`

An educational platform integrating AI-powered features into the learning process.

**My role: Backend Developer**

- Developed backend functionality and REST API endpoints.
- Implemented JWT / OAuth authentication.
- Integrated Google Gemini API.
- Worked on dynamic educational content generation.
- Implemented data storage using SQLite.

---

### 🌍 Arctic Network — Climate Monitoring

`React` `Node.js` `TypeScript` `Tailwind CSS`

A web platform for environmental monitoring and climate data visualization.

**My role: Fullstack Developer**

- Developed client-server functionality.
- Integrated REST APIs.
- Implemented time-series data handling.
- Built interactive dashboards and visualizations.
- Developed frontend components using React and Tailwind CSS.
